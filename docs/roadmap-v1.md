# Novel Agent V1 Roadmap

更新时间：2026-05-21

## 1. 文档作用
本文件定义 V1 的阶段顺序、每阶段交付物与验收标准，用于执行跟踪与复盘。

## 2. 阶段规划

## V1-0 基线确认（已完成，承接 MVP）
- 说明：以下内容已在 MVP 末期完成，不再重复实施：
  - 后端 API 主链路集成测试（Auth/Novels/Characters/Chapters）
  - 集成测试安全护栏（`INTEGRATION_TEST` + `_test` 库名约束）
  - 前端第一轮结构拆分与错误提示统一
  - 备份/恢复脚本与文档

## V1-1 世界观知识卡后端最小闭环（已完成）
- 目标：先落地修仙等题材复杂设定的数据底座。
- 交付物：
  - 新增 `lore_entries` 与 `lore_entry_characters` 数据结构。
  - 新增后端 API：`/novels/:novelId/lore-entries` CRUD。
  - 支持 `character_ids` 多对多绑定（空/单人/多人）。
- 验收：
  - `go test ./...` 通过。
  - API 层具备权限隔离与基础参数校验。

## V1-2 测试增量补强（已完成）
- 目标：在既有基线上补齐高风险失败路径与边界场景。
- 交付物：
  - 后端 API：补齐权限失败、参数非法、状态冲突场景。
  - 前端：章节写作主链路最小测试（生成/保存/提示）。
- 验收：
  - 测试可在约束环境稳定运行。
  - 不影响开发主库数据。

完成情况：
- 已完成后端 `chapters/generate` 失败路径集成测试补强。
- 已完成前端关键交互最小测试（生成失败提示、重试状态、请求参数携带）。

## V1-3 前端结构重构增量（不改功能）
- 目标：进一步降低页面复杂度和重复逻辑。
- 交付物：
  - 剩余重页面拆分为 hooks/components。
  - 重复状态与表单逻辑继续抽象复用。
- 验收：
  - 关键页面行为不变。
  - `npm run build` 通过。

## V1-4 世界观知识卡前端与生成联动（已完成）
- 目标：支持修仙等题材中的“法器/丹药/阵法”等复杂设定管理。
- 交付物：
  - 新增设定卡前端管理页（最小 CRUD）。
  - 支持人物多选绑定与列表展示。
  - 生成章节时可选择性注入设定卡上下文。
- 验收：
  - 能创建、编辑、查询、删除设定卡（前后端闭环）。
  - 生成接口能按选择带入设定信息。

完成情况：
- 已完成前后端设定卡 CRUD 闭环。
- 已完成“生成接口按选择带入设定信息”。

## V1-5 章节编辑体验优化（增量）
- 目标：提升长文写作效率与可控性。
- 交付物：
  - 结合设定卡信息优化编辑侧栏与提示区。
  - 关键交互细节继续优化（按钮、面板、异常提示）。
- 验收：
  - 常见操作路径无明显阻塞。
  - 用户可直观看到当前状态与下一步动作。

完成情况（增量）：
- 已完成章节生成质量控制参数闭环：
  - 后端 prompt 新增目标字数范围与风格硬约束。
  - 前端写作页新增目标字数下限/上限与风格约束勾选项。
  - 参数通过 `chapters/generate` 全链路透传并持久化到本地草稿。

## V1-6 稳定性与运维文档（增量）
- 目标：降低误操作和环境问题。
- 交付物：
  - 增加迁移回滚手册与风险清单。
  - README 的环境分层说明补齐（dev/test/prod）。
- 验收：
  - 新环境可按文档完成启动。
  - 高风险操作前后流程清晰。

完成情况（增量）：
- 已新增 AI 章节生成调参指南（题材参数组合、指令模板、质量问题排查）。
- 已新增环境分层模板与 README 说明（dev/test/prod）。
- 已完成生成可观测性第一步：返回 token 用量并记录生成耗时/模型/失败日志。
- 已完成前端生成失败提示分级：解析失败/请求失败/超时网络失败分别提示下一步动作。
- 已完成标准错误码对齐：后端返回 `code`，前端优先按错误码映射提示。

## V1-7 生成效率优化（增量）
- 目标：降低重复生成成本，提升写作过程中的版本可回溯性。
- 交付物：
  - V1-7.1：本地生成历史（按章节维度，保留最近 3 次）
  - V1-7.2：生成历史对比与防误覆盖
  - V1-7.3：生成配置模板化（内置模板 + 一键套用）
- 验收：
  - 可查看最近 3 次生成记录并一键回填。

完成情况（增量）：
- 已完成 V1-7.1：章节写作页支持本地历史记录与回填。
- 已完成 V1-7.2：回填前对比预览与二次确认，避免误覆盖当前内容。
- 已完成 V1-7.3：生成参数模板化与按小说本地记忆。

## V1-8 AI 配置易用性（增量）
- 目标：降低 OpenAI 配置门槛，避免每次通过终端 `export` 才能使用生成能力。
- 交付物：
  - V1-8.1：新增“用户级 AI 设置”页（API Key / Base URL / Model）。
  - 后端新增用户设置存储与读取接口。
  - 章节生成优先读取用户配置，缺省时回退到服务端环境变量。
- 验收：
  - 用户可在前端保存 AI 配置并立即用于章节生成。
  - API Key 在界面仅显示掩码，不明文回显。

完成情况（增量）：
- 已完成 V1-8.1：前端设置入口 + 后端配置存储 + 生成链路接入。
- 已完成 V1-8.6：多 Provider（OpenAI/Gemini）接入与前后端设置联动。

## V1-9 生成质量与修订效率（增量）
- 目标：提高长文本生成稳定性，并减少重试成本。
- 交付物：
  - V1-9.1：生成质量反馈闭环（评分/备注驱动下一轮）
  - V1-9.2：段落稳定化 + 生成前 token/费用预估
  - V1-9.3：生成后快速修订（润色/压缩/重排）
  - V1-9.4：段落级局部重写（选中文本 + 额外提示词）
  - V1-9.5：局部重写范围可视化与替换落点优化
- 验收：
  - 长文本生成可读性提升，整段无换行问题显著下降。
  - 生成前可看到估算成本区间。
  - 可基于现有正文进行一键修订，不必每次全量重生。

完成情况（增量）：
- 已完成 V1-9.1：反馈保存并自动注入下一轮生成。
- 已完成 V1-9.2：后端段落归一化 + 前端生成成本估算展示。
- 已完成 V1-9.3：写作页快速修订三按钮与复用生成链路。
- 已完成 V1-9.4：正文选中文本后可局部重写，仅替换选中段落并支持单独提示词。
  - 交互定稿：局部重写为固定按钮（未选中禁用，选中可用）。
  - 重写完成后弹出右侧居中预览窗，先看“原文/重写结果”再决定“应用替换/放弃替换”。
- 已完成 V1-9.5：局部重写确认体验优化。
  - 预览窗显示本次替换范围（起止字位与长度）。
  - 应用替换后光标落到重写段落末尾，并提示已替换范围。

## V1-10 章节资产管理（增量）
- 目标：为后续 RAG/对话生成准备更易检索的章节资产视图。
- 交付物：
  - V1-10.1：章节多条件检索（关键词 + 分卷 + 角色）
  - V1-10.2：章节状态流（草稿/待审/定稿）
  - V1-10.3：章节版本快照（手动存档点）
- 验收：
  - 章节较多时可快速定位目标章节。
  - 检索条件可组合使用，且不影响现有编辑链路。

完成情况（增量）：
- 已完成 V1-10.1：章节多条件检索（前端最小闭环）。
  - 关键词检索升级为“编号/标题/正文”。
  - 新增分卷筛选（全部分卷 / 指定分卷）。
  - 新增角色筛选（全部角色 / 指定角色；按角色名/别名匹配章节文本）。
- 已完成 V1-10.2：章节状态流（草稿/待审/定稿）最小闭环。
  - 后端章节模型新增 `status` 字段，迁移文件已落地并执行。
  - 章节编辑页可设置状态；章节列表支持状态筛选。
  - 章节列表支持快速切换单章状态（草稿/待审/定稿）。
- 已完成 V1-10.3：章节版本快照（本地最小版）。
  - 写作页新增“快照”侧栏入口，可手动保存当前章节快照。
  - 快照包含标题/状态/正文/大纲/总结，并按章节维度本地保存（最多 10 条）。
  - 支持一键回填快照，恢复到对应内容状态。

## 3. 执行规则
- 每个子阶段独立分支。
- 每个子阶段单独提交并更新 `docs/.local-progress.md`。
- 若阶段目标变化，先更新本 Roadmap 再开发。
