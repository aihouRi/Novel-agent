# AI 章节生成调参指南（V1）

更新时间：2026-05-20

## 1. 适用范围
本指南用于当前 MVP/V1 的章节生成面板，帮助你更稳定地产出中文网文风格内容。

当前可调参数：
- 目标字数下限 `target_word_min`
- 目标字数上限 `target_word_max`
- 避免翻译腔 `avoid_translation_tone`
- 避免现代网络口语 `avoid_modern_slang`
- 保持叙事视角一致 `keep_pov_consistent`
- 保持时态一致 `keep_tense_consistent`

## 2. 快速推荐组合

### 2.1 修仙主线推进章
- 目标字数：`2200 ~ 3200`
- 开关建议：全开
- 指令补充建议：
  - 本章推进一个明确事件（突破/冲突/交易/伏笔）
  - 结尾留一个下一章钩子

### 2.2 战斗章
- 目标字数：`1800 ~ 2600`
- 开关建议：全开
- 指令补充建议：
  - 战斗分三段：试探 -> 爆发 -> 收束
  - 每段要有“战术变化”而非纯喊招式

### 2.3 日常过渡章
- 目标字数：`1400 ~ 2200`
- 开关建议：全开
- 指令补充建议：
  - 保留信息增量（人物关系变化/资源变化/线索变化）
  - 避免纯流水账

### 2.4 情绪与人物关系章
- 目标字数：`1600 ~ 2400`
- 开关建议：全开
- 指令补充建议：
  - 明确主视角人物
  - 至少出现一次“行为细节 + 心理变化”的对应

## 3. 指令模板（可直接改）

```text
目标：生成第X章，主视角为【人物名】。
剧情要求：推进【具体事件】，并回收【旧伏笔】的一部分信息。
人物要求：本章重点表现【人物A】与【人物B】的关系变化。
风格要求：中文网文自然表达，避免翻译腔，不要现代网络口语。
结构要求：开头快速入戏，中段冲突升级，结尾留下下一章悬念。
```

## 4. 常见问题排查

### 4.1 生成太短
- 提高目标字数范围，例如从 `1800~2600` 提到 `2400~3200`。
- 在指令里增加“必须包含的场景节点”（2-3 个）。

### 4.2 生成空泛
- 在“本章相关设定”里勾选更具体的设定卡。
- 在“本章登场人物”只选择必要角色，避免信息噪音。

### 4.3 语言有翻译感
- 保持“避免翻译腔”开启。
- 指令中加入“使用中文网文常见节奏与句法，减少长复合句”。

### 4.4 人物跑偏
- 勾选该章真实登场人物，不要放过多无关角色。
- 指令里加一句“人物言行必须符合既有人设，不得突变”。

## 5. 使用顺序建议
1. 先选本章真实登场人物（不求多）。
2. 再选本章确实会用到的设定卡。
3. 填写章节目标与结构指令。
4. 设定目标字数范围并保持四个风格开关开启。
5. 生成后先读 `outline` 与 `summary`，满意再保存正文。
