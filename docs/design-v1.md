# Novel Agent V1 设计书

更新时间：2026-05-21

## 1. 文档目的
本设计书用于定义 V1 的目标、范围与约束，作为 MVP 之后的迭代基线。

## 2. V1 目标
在不偏离 MVP 核心方向的前提下，提升三个方面：
- 稳定性：减少回归与线上故障概率。
- 可维护性：降低前后端后续迭代成本。
- 写作体验：改进章节编辑与 AI 生成流程体验。

## 3. 承接 MVP 已完成基线（不在 V1 重复计入）
以下能力已在 MVP 后期完成，不再作为 V1 新目标重复计算：
- 测试与安全基线：
  - 集成测试显式开关（`INTEGRATION_TEST=1`）。
  - 测试库命名护栏（`MYSQL_DSN` 必须包含 `_test`）。
  - API 集成测试已覆盖 Auth/Novels/Characters/Chapters 主链路。
- 前端可维护性改造（第一轮）：
  - 大页面拆分到 hooks/components（已进行多轮）。
  - API 错误提取逻辑统一。
- 章节编辑体验（第一轮）：
  - 生成中状态提示。
  - 生成失败重试入口与提示优化。
- 运维基础：
  - MySQL 备份/恢复脚本与 README 使用说明。

## 4. V1 范围（新增）
- 测试体系补强（增量）：
  - 补齐失败路径与边界场景（权限、参数、状态冲突）。
  - 增加前端关键流程测试，先覆盖高风险写作链路。
- 工程结构重构（增量，不改业务功能）：
  - 继续拆分剩余重页面和重 hook。
  - 进一步去重同构状态与表单逻辑。
- 写作与设定体验（增量）：
  - 修仙题材等复杂设定的结构化管理（如法器/丹药/阵法等知识卡）。
  - 编辑页对“高频写作辅助信息”提供更顺手的展示/调用方式。
- 运维与发布（增量）：
  - 增加“安全迁移 + 回滚”操作手册。
  - 增加开发/测试/生产环境配置分层说明。
  - 增加 AI 生成调参指南（参数组合 + 指令模板 + 排查手册）。

- V1-1 已完成：Lore Entries 后端最小闭环
  - 新增 `lore_entries` + `lore_entry_characters` 结构

  - 绑定人物支持：空 / 单人 / 多人
  - 权限约束：`character_ids` 必须属于当前用户的当前小说
- V1-4（前半）已完成：Lore Entries 前端最小闭环
  - 左侧导航新增“小说设定”
  - 前端已支持设定卡列表/创建/编辑/删除
  - 设定卡表单支持人物多选绑定
- V1-4（后半）已完成：章节生成联动设定卡
  - 章节生成接口支持 `lore_entry_ids`
  - 写作页支持“本章相关设定”多选
  - 生成 prompt 可注入所选设定卡信息
- V1-5（前半）已完成：小说工作区信息架构重构
  - 左侧导航改为“小说列表直接选择”
  - 右侧改为横向 Tab 切换四个模块
  - 移除四个模块内重复“选择小说”步骤
- V1-5（后半）已完成：章节生成质量控制参数
  - 章节生成接口支持目标字数范围：`target_word_min / target_word_max`
  - 章节生成接口支持风格硬约束开关：
    - `avoid_translation_tone`
    - `avoid_modern_slang`
    - `keep_pov_consistent`
    - `keep_tense_consistent`
  - 写作页“生成指令”面板已接入对应表单项与本地草稿持久化
  - “最近章节参考数”已迁移到章节写作页生成面板（本次生成参数），不再放在小说详情编辑中
- V1-6（文档部分）已完成：环境分层模板与说明
  - 新增 `.env.example`、`.env.dev.example`、`.env.test.example`
  - README 增加 dev/test/prod 分层约定与加载示例
- V1-6（可观测性第一步）已完成：生成 token 与日志
  - 章节生成响应增加 `model + usage(prompt/completion/total tokens)`
  - 后端日志记录生成耗时、模型、token 使用量与失败信息
  - 前端成功提示显示“本次消耗约 X tokens”
- V1-6（交互增强）已完成：生成失败提示分级
  - 解析失败：提示“模型输出格式异常，建议重试/简化指令”
  - 请求失败：提示检查 API Key、额度、模型配置
  - 超时/网络失败：提示缩短字数后重试
- V1-6（协议增强）已完成：标准错误码 + 前端按码映射
  - 后端 `chapters/generate` 错误响应增加 `code`
  - 前端优先按 `code` 映射提示，文本关键字匹配作为兜底
- V1-7.1 已完成：本地生成历史（按章节维度）
  - 章节写作页新增“历史”侧栏按钮
  - 本地保存最近 3 次生成结果（含时间、模型、token、指令摘要）
  - 支持一键回填某次历史生成结果到当前编辑器
- V1-7.2 已完成：历史回填防误覆盖（最小版）
  - 回填前弹出确认框
  - 提供“当前内容 vs 历史版本”预览对比
  - 需二次确认后才执行回填
- V1-7.3 已完成：生成配置模板化（最小版）
  - 提供内置模板：修仙主线推进/战斗章节/日常过渡/情绪与关系
  - 模板一键套用：字数范围、参考章节数、风格开关、指令骨架
  - 本地记住上次所选模板（按小说维度）
- V1-8.1 已完成：用户级 AI 配置（最小版）
  - 前端用户菜单新增“AI 设置”弹窗，可配置：
    - `openai_api_key`
    - `openai_base_url`
    - `openai_model`
  - API Key 仅回显掩码，不回显明文。
  - 后端新增用户级配置表，并以加密形式存储 API Key。
  - 章节生成调用时优先读取用户级配置，未配置时回退到服务端环境变量。
- V1-8.6 已完成：多 Provider（OpenAI / Gemini）接入
  - AI 设置新增 `provider` 切换与 Gemini 配置项。
  - 后端生成链路支持按 provider 动态选择 OpenAI 或 Gemini 客户端。
  - 生成失败提示补充 Gemini Key 未配置场景。
- V1-9.1 已完成：生成质量反馈闭环（最小版）
  - 写作页支持“满意/一般/不满意 + 备注”反馈。
  - 下一次生成会自动注入上一轮反馈，减少盲目重试。
- V1-9.2 已完成：生成稳定性与成本预估
  - 后端增加正文分段约束与分段归一化兜底，降低整段无换行概率。
  - 生成前确认弹窗展示估算 input/output tokens 与费用区间（提示级）。
- V1-9.3 已完成：生成后快速修订（最小版）
  - 写作页新增“快速润色/快速压缩/重排段落”三个动作。
  - 复用现有生成链路，不新增后端 API。
- V1-9.4 已完成：段落级局部重写（最小版）
  - 正文选中文本后可触发“局部重写”。
  - 支持填写“本段额外提示词”。
  - 仅替换选中段落，不覆盖整章正文。

  - 重写后显示右侧居中预览弹窗，展示“原文 vs 重写结果”，由用户确认应用或放弃。
- V1-9.5 已完成：局部重写确认体验优化
  - 预览弹窗增加替换范围信息（起止字位 + 长度）。
  - 应用替换后，光标自动落到新段落末尾，并提示替换范围。

  - 新增 `chapters/generate` 失败场景集成测试

## 6. V1 非目标
- RAG / 向量数据库
- MCP / 多 Agent 编排
- Google Drive 集成
- 商业化复杂 UI 与完整运营后台

## 7. 约束与原则
- 延续 Go + Echo + React + TypeScript + MUI 技术栈。
- 优先做“小步提交 + 可回滚”的阶段改造。
- 单阶段只做一件事：需求明确、验收明确、文档同步。
- main 分支始终保持可启动、可迁移、可验证。

## 8. 验收标准（V1 总体）
- 后端：关键主链路集成测试可在测试库稳定通过。
- 前端：核心页面交互可用，错误提示一致，复杂页面进一步降复杂度。
- 文档：README、设计书、阶段总结同步更新。
